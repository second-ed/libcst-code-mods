Case¶

Pre-transformer:

def simple_loop_with_if_else() -> None:
    for i in range(10):
        if i % 2 == 0:
            print(f"{i} is even")
        else:
            print(f"{i} is odd")

Post-transformer:

def simple_loop_with_if_else() -> None:
    for i in range(10):
        if i % 2 != 0:
            print(f"{i} is odd")
            continue
        print(f"{i} is even")
